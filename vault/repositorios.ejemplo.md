# Repositorios conectados (ejemplo)

Copia este archivo como `repositorios.md` y pon las rutas de TU máquina. `repositorios.md` no se sube al repositorio porque cada persona tiene rutas distintas.

Solo para **visualizar**: `npm run sync` hace únicamente `git fetch` y lecturas; no hace commit, push ni pull.

Formato: `- <proyecto> | <ruta local>`. El proyecto es una carpeta de `proyectos/`.

- socrates | ~/ruta/a/socrates.app
- cotizador | ~/ruta/a/cotizador
- programas-educativos | ~/ruta/a/programas-educativos
- calculadoraguate | ~/ruta/a/calculadoraguate
